# 🎃 Halloween Powered By Kapil
### *A Spooky Gamified Learning Odyssey by SARLAYASH PRODUCTIONS*

An atmospheric, horror-themed educational video game blending **Data Structures & Algorithms (DSA)**, **Quantitative Aptitude & Logical Reasoning**, **Emotional Intelligence & Soft Skills**, and **Alchemical Gamification**.

---

## 🌟 Game Highlights

- **🎡 Kapil's Wheel of Trick or Treat (`wheel.js`)**:
  - 8 occult segments alternating between **TREATS** (Spectral Shields, 50:50 Intuition Elixirs, Occult XP, Royal Titles) and **TRICKS** (speed DSA challenges, logic riddles, crisis scenarios).
  - Web Audio API physical wheel clicking, deceleration, and triumphant fanfares.
  - Sits at the heart of the gamification loop: use earned **Spectral Shields** to auto-solve tough questions and **50:50 Elixirs** to eliminate false options during quizzes!
  - Earn **+2 bonus spins** every time you conquer any of the 5 realms!

- **5 Distinct Occult Levels**:
  1. **Level 1**: *Crypt of Algorithms & Data Structures* (Trees, Heaps, Graphs, DP, Sorting, Traversals)
  2. **Level 2**: *Haunted Labyrinth of Aptitude* (Puzzles, Blood Moon Clocks, Speed & Distance, Probability)
  3. **Level 3**: *Chamber of Whispering Shadows* (Soft Skills, EQ, Conflict Resolution, Crisis Leadership)
  4. **Level 4**: *The Cursed Alchemist's Gamified Crucible* (Gamified code debugging under pressure)
  5. **Level 5**: *The Grand Necromancer's Final Trial* (Supreme 300-MCQ Final Assessment with a strict 1-Hour Witching Timer)

- **👻 Spooky Procedural Audio Engine (`audio.js`)**:
  - Haunted low-pass sub-bass drone and spectral whistling winds synthesized via the browser's **Web Audio API** (no external audio files needed).
  - Cathedral toll bells, rhythmic countdown heartbeats, jumpscare dissonant stingers, wheel clicking pegs, and level completion chimes.
  - Sound toggle button with ambient mute/unmute control.

- **🏆 Occult Badges Vault**:
  - Earn 5 unique badges for conquering each realm stamped with Kapil's Occult Medallion:
    - 💀 *Necromancer of Algorithms*
    - 🔮 *Labyrinth Mind Weaver*
    - 🕯️ *Specter of Emotional Intelligence*
    - 🧪 *Alchemical Code Master*
    - 👑 *Halloween Grandmaster Scholar*

- **⏳ 300-MCQ 1-Hour Final Assessment Engine**:
  - 60-minute countdown clock with urgency pulsing and heartbeat cues.
  - 300-question interactive navigation palette grid (Answered, Marked for Review, Current).
  - Category tags across DSA, Aptitude, and Soft Skills.

- **📜 High-Definition Certificate Generator (`certificate.js`)**:
  - Renders a 1920x1080 canvas with gothic gold borders, official Sarlayash Productions wax seal, and Kapil's signature medallion.
  - **Zero Text Overlapping or Spillover Guarantee**: Utilizes adaptive dynamic font scaling and bounded line-wrapping algorithms.
  - Direct **PNG Download** with sanitized filenames.
